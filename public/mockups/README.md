# Estrutura de Mockups

Esta pasta contém todas as imagens base para geração de mockups de uniformes.

## Organização

### /camiseta
Imagens base da camiseta em frente e costas
- `camiseta-frente-{cor}.png` - Frente da camiseta
- `camiseta-costas-{cor}.png` - Costas da camiseta

**Cores esperadas:** preto, branco, cinza, azul

Exemplo:
- camiseta-frente-preto.png
- camiseta-frente-branco.png
- camiseta-costas-preto.png
- camiseta-costas-branco.png

Exemplo:

## Formato das imagens

- Formato: PNG (com transparência) ou JPEG
- Tamanho recomendado: Alta resolução (mínimo 1000x1000px)
- Dimensões: Uniforme (todas as cores do mesmo modelo devem ter mesmas dimensões)
